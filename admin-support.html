Project 3: Community Fee Administration System

Admin Support Spreadsheet Management | Google Sheets | GitHub Pages

A fee administration system for a housing committee, built on Google Sheets

A housing committee tracked monthly community fees in a large Google Sheets file full of formulas and settings. One wrong click could delete data, so I built a simple web interface on top of the same sheet.

What It Does

  • Dashboard with house totals, paid vs. unpaid this month, accumulated arrears, and a list filterable by block and payment status.
  • Separate login page for the committee to add and manage transactions without opening the spreadsheet.
  • Payment instructions with WhatsApp confirmation links for residents.

How It Works

One Google Sheets file stays the single source of truth. Google Apps Script connects it to web pages (HTML, CSS, JavaScript) on GitHub Pages, so formulas and settings stay hidden.

My role: I designed the workflow, data structure, and logic, used AI assistance for coding, and maintained up-to-date payment records.
