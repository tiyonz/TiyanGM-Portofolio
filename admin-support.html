Project 2: Inventory & Sales Tracking System

Data Entry & Admin Support Tools: Microsoft Excel
Part 1: Workflow & System Setup Slide 6

System Context

An end-to-end Excel system, from purchasing to profit reporting. Built and used daily for an investor-backed import and distribution venture (beef and frozen buffalo) across West Java and other regions, as part of a 4-person founding team.

Workflow

Master Data → PO → Stock In → Invoice / Stock Out → Stock Balance → Reports

What It Does

  • Records POs, stock in, stock out, and adjustments for shrinkage.
  • Prints POs and invoices, and updates stock balances (opening, in, out, available) automatically.
  • Reports sales, margin, payables, receivables, and daily profit and loss.
My Role: I designed the workflow and built the sheets with simple formulas, entered the data daily, and prepared weekly and monthly reports, working with teammates on logistics and finance.

Project 3: Community Fee Administration System

Admin Support Tools: Google Sheets | GitHub Pages | Apps Script
Part 1: Problem & Administrative Solution Slide 8

System Context

A fee administration system for a housing committee, built on Google Sheets. A housing committee tracked monthly community fees in a large Google Sheets file full of formulas and settings. One wrong click could delete data, so I built a simple web interface on top of the same sheet.

What It Does

  • Dashboard with house totals, paid vs. unpaid this month, accumulated arrears, and a list filterable by block and payment status.
  • Separate login page for the committee to add and manage transactions without opening the spreadsheet.
  • Payment instructions with WhatsApp confirmation links for residents.

How It Works

One Google Sheets file stays the single source of truth. Google Apps Script connects it to web pages (HTML, CSS, JavaScript) on GitHub Pages, so formulas and settings stay hidden.

My Role: I designed the workflow, data structure, and logic, used AI assistance for coding, and maintained up-to-date payment records.
