Project 3: Community Fee Administration System

Admin Support Google Sheets | Apps Script | GitHub Pages

Objective

A fee administration system for a housing committee. A housing committee tracked monthly community fees in a large Google Sheet full of formulas. One wrong click could delete data, so I built a simple web interface on top of the sheet.

What It Does

  • Dashboard with house totals, paid vs. unpaid this month, and arrears filterable by block
  • Separate login page for the committee to add transactions without altering the base sheet
  • Payment instructions with WhatsApp confirmation links for residents

How It Works

One Google Sheets file stays as the single source of truth. Google Apps Script connects it to web pages (HTML, CSS, JS) on GitHub Pages, keeping formulas and settings protected.

My Role: Workflow design, data structure, logic, and maintaining accurate monthly records.
